# elo. — Placas personalizadas

Site responsivo inspirado nas telas de referência criadas no Figma.

## Arquivos
- `index.html`: página inicial e formulário de personalização.
- `style.css`: identidade visual premium e layout responsivo para desktop e celular.
- `script.js`: prévia ao vivo, cores, formato, tamanho, upload de logotipo e resumo para WhatsApp.

## Executar
Abra `index.html` no navegador ou publique o repositório com GitHub Pages, Cloudflare Pages ou Vercel.

## Importante
Este é um protótipo de front-end. Os preços exibidos são valores demonstrativos, o QR code é ilustrativo e não gera um QR real para avaliação. Não há ainda carrinho, banco de dados, checkout ou pagamento integrado. As fotos de ambiente são carregadas do Unsplash e a fonte é carregada do Google Fonts.
